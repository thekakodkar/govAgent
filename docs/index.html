Governed execution for agentic AI

govAgent is a Python library that wraps LLM calls and registered tools with policy YAML, fiscal circuit breakers, PII redaction, semantic alignment checks, Harbor artifact verification, human-in-the-loop approval, and a default JSONL audit log.

Beta, not a certification. This page describes govagent 3.4.0 (pyproject.toml and govagent.__version__). govAgent does not certify systems under the EU AI Act, ISO/IEC 42001, or the NIST AI RMF.

Overview

Public imports:

from govagent import ExecutiveAgent, tool, Policy, registry, __version__

The standard path is: load a Policy, register tools with @tool, inject a router that returns LLMResponse, then await agent.execute(task). The loop redacts PII, runs SemanticGuard on the sanitized task, routes the request (including a real contains_pii flag), validates the tool schema, applies fiscal and judiciary guards, verifies Harbor when OCI fields are set, and invokes the registered Python callable.

Install

pip install "govagent[enterprise]"
python -m spacy download en_core_web_lg
  • Requires Python 3.10, 3.11, 3.12, or 3.13 (>=3.10,<3.14).
  • The core wheel includes Presidio, spaCy, Pydantic, YAML, httpx, Slack, AWS and Azure telemetry clients, and opentelemetry-api.
  • govagent[enterprise] adds sentence-transformers (local MiniLM embeddings). Without it, ExecutiveAgent still constructs; SemanticGuard logs a warning and fails open until the extra is installed.
  • Optional extras: crewai, langchain.
  • To use the current main behavior before the next PyPI publish: pip install "govagent[enterprise] @ git+https://github.com/thekakodkar/GovAgent.git".
  • Privacy analysis expects the spaCy model en_core_web_lg.

Quickstart

import asyncio
from govagent import ExecutiveAgent, tool, Policy
from govagent.hitl import HITLManager
from govagent.llm.base import LLMResponse

@tool(name="execute_financial_transaction", risk_level="high")
def pay(amount: float) -> str:
    return f"paid:{amount}"

class Router:
    async def route_and_generate(self, request, context):
        return LLMResponse(
            text="pay the invoice",
            tool_calls=[{"name": "execute_financial_transaction", "args": {"amount": 25}}],
            raw_usage={"total_tokens": 12, "estimated_cost_usd": 0.01},
            model_name="local-script",
        )

class AutoApprove:
    async def notify(self, request):
        return True

async def main():
    policy = Policy.from_yaml("policies/finance_policy.yaml")
    agent = ExecutiveAgent(
        persona=policy.agent_name,
        policy=policy,
        router=Router(),
        hitl_manager=HITLManager(adapter=AutoApprove()),
    )
    snapshot = await agent.execute("Pay Jane Doe at 123 Main St")
    print(snapshot.status, snapshot.output, snapshot.selected_model)

asyncio.run(main())

On this policy, execute_financial_transaction is high-risk, so HITL runs. The example injects an auto-approving adapter so a script can finish; in production, use Slack or another adapter. The registered pay function is actually called. Float costs are accepted, and snapshot.selected_model / metrics["selected_model"] report local-script (from LLMResponse.model_name).

Features

Policy projection

registry_alignment.allowed_tools and high_risk_tools are read, as is a top-level tools: list (which wins for the same name). oversight.judiciary and top-level judiciary feed policy.judiciary_settings. Nested fiscal limits including recursive_tco_limit → recursive_tco_ceiling still project as before.

Tool dispatch

perform_action resolves the allow-list, runs Harbor when OCI repository and digest are set, and invokes the registered callable (sync or async). The return value is str(result).

Guards

SemanticGuard runs on the sanitized task and on tool thought. The circuit breaker enforces daily / TCO caps and transaction_ceiling / max_per_transaction. High-risk tools require HITL via judiciary_settings.

Privacy and routing

Presidio redacts the prompt. last_execution_had_pii is set so HYBRID contains_pii routing rules can fire. Policy oversight.privacy.target_entities (for example CREDIT_CARD) extend the default entity list. anonymize() is an alias of redact_task.

Audit log and telemetry

By default, TelemetryManager appends JSONL to logs/audit_trail.jsonl (override with GOVAGENT_AUDIT_LOG; disable with GOVAGENT_DISABLE_AUDIT_LOG=1 or persist_jsonl=False). Optional OpenTelemetry GenAI spans emit when a TracerProvider is configured and OTEL_SDK_DISABLED is unset.

What this library is not

It is not a full MCP server, not an ISO 42001 or NIST AI RMF management system, and not a substitute for a provider’s EU AI Act obligations. The in-repo FastAPI sandbox is excluded from the published wheel and requires GOVAGENT_SECRET_TOKEN — there is no default bearer token.

Policy YAML

Sample files under policies/ (including finance_policy.yaml) use registry_alignment and oversight. Those keys are now enforced. Allow-list membership is checked at execute time so a process-wide registry can hold tools used by other policies.

Projected view

Execute loop

  1. Redact the task with PrivacyGuard; start a telemetry trace; record whether PII was found.
  2. Run SemanticGuard on the sanitized text (blocked if a prohibited strategy meets the threshold).
  3. If router is None, return a sandbox success (no guards beyond the above). This is a test helper, not a production mode.
  4. Route and generate. contains_pii in the routing context is true when redaction found entities. Metrics use model_name / selected_model. raw_usage may include float estimated_cost_usd.
  5. Parse a tool call, or finish if the model says it is complete.
  6. Schema-validate the intent. Invalid amounts finish as blocked, not error.
  7. Evaluate fiscal caps (including per-transaction ceilings), semantic thought, and judiciary if is_high_risk.
  8. Allow-list check, Harbor verification when OCI fields are present, then call the registered function. A tool named execute_financial_transaction still ends the loop after one successful call (maximum 10 steps otherwise).

Compliance mapping

Not a certification and not “regulation ready” by installation alone. The mapping below is how current main can help a deployer. Legal obligations remain on the provider or deployer of the AI system. govAgent itself is not a GPAI model and is not ISO/IEC 42001 or NIST AI RMF certified.
FrameworkWhat the library can contributeWhat it does not do
EU AI Act Article 9 (risk management & data) Prompt PII redaction; optional policy entity lists; semantic interception of prohibited strategies on the execute path. Does not implement a full risk-management system, residual-risk register, or data-governance programme.
EU AI Act Article 12 (logging) Default append-only JSONL audit trail; optional cloud exporters; optional OpenTelemetry GenAI spans; in-memory traces with parent IDs for swarms. The file log is not a WORM / legally immutable archive by itself. You still choose retention, access control, and official record-keeping.
EU AI Act Article 14 (human oversight) HITL for tools that policy marks high-risk, including M-of-N settings projected from oversight.judiciary. Slack and CLI adapters exist. Default CLI prompting is not an enterprise courtroom. You must wire a real approval channel and operating procedure.
ISO/IEC 42001 / NIST AI RMF Reusable technical controls (policy, logs, human gates) that an AIMS or RMF programme could cite. No Statement of Applicability, no GOVERN/MAP/MEASURE/MANAGE workbook, no certified management system.
