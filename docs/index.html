govAgent v3.4.0 - Library Documentation

govAgent is a Python library that wraps an LLM call in declarative policy enforcement, privacy redaction, tool-schema validation, a fiscal circuit breaker, and cryptographic execution snapshots. This guide documents the public package govagent as verified against current main (library version 3.4.0). Features added after the 3.4.0 tag remain on main until the next PyPI publish.

Python >=3.10,<3.14 PyPI: govagent 3.4.0 MIT License Extras: crewai, langchain, enterprise, openai, anthropic, mcp

Which API Should I Use?

Start from the core primitives exported by from govagent import ExecutiveAgent, tool. Specialized governance engines and adapters are imported directly from their respective submodules.

Use CaseEntry PointReturnsImplementation Behavior
Load a YAML or dict policy Policy.from_yaml(path) or Policy(config) Policy Projects nested fiscal_governance.global_limits and alignment, plus registry_alignment and the top-level tools: list. For a given tool name, a top-level tools: entry wins.
Register a tool @tool(name=..., risk_level=..., ...) Original callable Registers on the process-wide registry singleton. ExecutiveAgent.perform_action resolves the callable through Harbor and invokes it.
Run a governed task await agent.execute(task) ExecutionSnapshot Redacts prompt, runs SemanticGuard, invokes router.route_and_generate or await agent.aexecute(task), validates intent, applies fiscal and judiciary rails, and calls the registered tool. execute remains an awaitable wrapper around aexecute. router=None returns sandbox success without an LLM (after the privacy and semantic checks).
Enforce fiscal ceilings CircuitBreaker.check_financial_risk(cost) None or raises GovernanceViolation Compares cumulative swarm spend plus projected cost against min(recursive_tco_ceiling, daily_budget_usd).
Redact PII in strings PrivacyGuard(policy).redact_task(text) str Uses Microsoft Presidio plus a custom street-address regex. Requires en_core_web_lg.
Score semantic alignment SemanticGuard(...).evaluate_alignment(text) float Returns 0.0 on a breach, otherwise 1.0 - max_similarity. Called from CircuitBreaker.evaluate and from ExecutiveAgent.aexecute. Without govagent[enterprise], vector checks fail open.
Route an LLM request PolicyBasedRouter.route_and_generate LLMResponse LOCAL_ONLY and CLOUD_ONLY always route to default_provider. Conditional rules execute only in HYBRID mode.
Verify a Harbor artifact registry.verify_and_resolve_tool(name) Callable or raises Invoked automatically by perform_action when OCI repository/digest fields are set. The offline mock-token stub remains for tests.
Generate audit & CFO packs EvidencePackGenerator, CFOAnalyticsEngine, MetaGovernor Models / dicts Exported directly from govagent.governance. Generated dossiers also reference the packaged control mapping (govagent.compliance); this is not a certification.

Installation & Setup

PyPI Package and Optional Extras pyproject.toml 3.4.0

pyproject.toml targets Python >=3.10,<3.14. The published distribution packages the core govagent library under src/.

# Core library (includes Presidio, spaCy, Slack, AWS, Azure, and OpenTelemetry dependencies)
pip install govagent==3.4.0

# Optional extras declared in pyproject.toml
pip install "govagent[enterprise]"   # sentence-transformers (optional local SemanticGuard embeddings)
pip install "govagent[crewai]"       # CrewAI governance adapter
pip install "govagent[langchain]"    # langchain-core, langchain-openai, openai
pip install "govagent[openai]"       # OpenAIClient and AzureOpenAIClient
pip install "govagent[anthropic]"    # AnthropicClient
pip install "govagent[mcp]"          # official MCP SDK used by GovernedMCPGateway

# Presidio's AnalyzerEngine (used by PrivacyGuard) requires the large English spaCy model
python -m spacy download en_core_web_lg

# Local repository development
poetry install --with dev --extras "crewai enterprise"
python -m spacy download en_core_web_lg
Runtime Dependency Note: ExecutiveAgent always constructs SemanticGuard during initialization. The enterprise extra (sentence-transformers) enables local all-MiniLM-L6-v2 checks. Without it, ExecutiveAgent still constructs; SemanticGuard logs a warning and fails open. A base pip install govagent==3.4.0 is sufficient to import and instantiate the core classes. Optional extras openai, anthropic, and mcp add cloud model clients and the official MCP SDK.

Core Concepts

Policy Projection Mechanics

Policy retains the raw YAML dictionary in policy.config and projects normalized attributes for runtime enforcement:

YAML KeyProjected AttributeRuntime Behavior
metadatametadata, agent_nameDefaults agent_name to UnknownAgent if omitted.
tools (list of dicts with name)tool_rules, allowed_toolsContributes to the allow-list (entries win over registry_alignment for the same name). Allow-list membership is enforced at execute / perform_action time. On initialization, validate_registry() still raises PermissionError if a tool's decorator risk_level is lower than the YAML specification.
infrastructure.routing_mode / default_provider / rulesrouting_mode, default_provider, routing_rulesDefaults to LOCAL_ONLY and local_ollama.
fiscal_governance.global_limits and/or top-level global_limitsglobal_limitsTop-level keys take precedence over nested keys. Nested recursive_tco_limit is normalized to recursive_tco_ceiling. If no top-level block is defined, defaults inject daily_budget_usd: 10.0.
alignmentalignmentForwarded to SemanticGuard as mission_statement, prohibited_strategies, and min_similarity_score (default 0.85).
judiciary (top-level)judiciary_settingsDefaults to Slack, confidence 0.9, timeout 300s. If the top-level key is absent, settings are taken from oversight.judiciary. oversight itself is projected onto policy.oversight.
registry_alignment.*tool_rules, high_risk_tools, allowed_toolsProjected. allowed_tools / high_risk_tools seed the allow-list and high-risk set. A top-level tools: entry still wins for the same name. is_high_risk() is true when the name is in high_risk_tools or the rule has require_human_approval / risk_level == "high".

The Execution Lifecycle

ExecutiveAgent.aexecute(task) runs an asynchronous control loop capped at 10 iterations. await agent.execute(task) is an unchanged awaitable wrapper around that method:

  1. Context & Privacy: Binds the active agent on a contextvar and redacts PII from the input prompt via PrivacyGuard.redact_task.
  2. Telemetry, Semantic & Sandbox Check: Starts a telemetry trace and runs SemanticGuard on the sanitized task. If router is None, returns with status success and output Task complete (Test Sandbox Mode).
  3. LLM Inference: Constructs an LLMRequest (temperature 0.0, system instruction You are a {persona}. Corporate Policy Boundaries apply.) and invokes router.route_and_generate.
  4. Completion Check: If the response contains no tool calls, or the action is complete (including the substring “complete” in response text), terminates with Task complete.
  5. Schema Validation: Executes registry.validate_intent_schema. Invalid monetary values, schema violations, or unregistered tools terminate the run as blocked (not error).
  6. Fiscal & Judiciary Guards: Calls CircuitBreaker.evaluate (semantic thought, per-transaction ceiling, then fiscal TCO). Judiciary approval triggers when policy.is_high_risk(action) is True.
  7. Action Dispatch: perform_action enforces the allow-list, verifies Harbor when OCI fields are set, and invokes the registered callable (returning str(result)). If the action name is execute_financial_transaction, the loop exits immediately after that step (maximum 10 steps otherwise).
  8. Terminal States: Any GovernanceViolation maps to blocked; unhandled exceptions map to error; exceeding 10 steps maps to timeout.
Scope of Execution Loop: CircuitBreaker.evaluate runs semantic alignment, per-transaction caps, and fiscal TCO. Harbor verification runs from perform_action when OCI fields are present. Optional OpenAIClient, AzureOpenAIClient, and AnthropicClient can be registered on a router; GovernedMCPGateway applies the same rails to MCP or local tool calls.

Use Case 2: Legislate Tools & Validate Intents @tool + registry

Import tool and registry from the top-level package. The decorator accepts name, description, risk_level (default "low"), oci_repository, artifact_digest, and schema. Tools named execute_financial_transaction automatically validate against FinancialTransactionIntent (amount required, extra fields forbidden) unless overridden.

from govagent import tool, registry, Policy

@tool(name="execute_financial_transaction", risk_level="high")
def execute_financial_transaction(amount: float):
    return amount

policy = Policy({
    "metadata": {"agent_name": "Treasury"},
    "tools": [
        {"name": "execute_financial_transaction", "risk_level": "high", "require_human_approval": True}
    ],
})
print(policy.allowed_tools)
print(policy.is_high_risk("execute_financial_transaction"))
print(registry.validate_intent_schema("execute_financial_transaction", {"amount": 10}))
print(registry.validate_intent_schema("not_a_published_tool", {}))

Use Case 3: Execute a Governed Task ExecutiveAgent.execute

Use ExecutiveAgent.bootstrap(policy_path, router_client, slack_channel=None) to load a YAML policy and initialize optional Slack HITL integration, or instantiate ExecutiveAgent directly. OllamaClient resides in govagent.llm.ollama.

Custom Router Integration

Any router implementing an async route_and_generate(request, context) -> LLMResponse method can drive execution. Setting risk_level="low" avoids triggering the blocking CLI HITL prompt during automated testing:

from govagent import tool, Policy
from govagent.agent import ExecutiveAgent
from govagent.llm.base import LLMResponse

@tool(name="execute_financial_transaction", risk_level="low")
def _payment(amount: float):
    return f"PAID {amount}"

class GoodRouter:
    async def route_and_generate(self, request, context):
        return LLMResponse(
            text="I will execute the payment now.",
            tool_calls=[{"name": "execute_financial_transaction", "args": {"amount": 10}}],
            raw_usage={"total_tokens": 4},
            model_name="scripted",
        )

policy = Policy({
    "metadata": {"agent_name": "Treasury"},
    "fiscal_governance": {"global_limits": {"daily_budget_usd": 100.0, "recursive_tco_limit": 150.0}},
})
agent = ExecutiveAgent(persona="Director", policy=policy, router=GoodRouter())
result = await agent.execute("Pay an invoice")

Use Case 4: Fiscal Circuit Breaker CircuitBreaker

CircuitBreaker sums the thread-isolated swarm spend ledger with the projected transaction cost and enforces min(recursive_tco_ceiling, daily_budget_usd) (evaluating to min(500, 100) = 100 for the sample finance policy). If both keys are omitted, defaults are ceiling 150.0 and daily budget 100.0.

from govagent.policy import Policy
from govagent.guards.circuit_breaker import CircuitBreaker, GovernanceViolation
from govagent.context import reset_fiscal_ledger, update_shared_spend, get_shared_fiscal_metrics

policy = Policy.from_yaml("policies/finance_policy.yaml")
reset_fiscal_ledger()
breaker = CircuitBreaker(policy, semantic_guard=None)

breaker.check_financial_risk(90.0)          # Allowed (90.0 <= 100.0)
try:
    breaker.check_financial_risk(150.0)     # Blocked (150.0 > 100.0)
except GovernanceViolation as exc:
    print(exc)

update_shared_spend(80.0)
print(get_shared_fiscal_metrics())
try:
    breaker.check_financial_risk(30.0)      # Blocked (80.0 + 30.0 = 110.0 > 100.0)
except GovernanceViolation as exc:
    print(exc)
Verified Output

{'cumulative_spend': 80.0, 'task_counter': 1.0}
RECURSIVE TCO REJECT: Projected swarm spend $110.00 exceeds the institutional limit of $100.00.

Use Case 5: Privacy Redaction PrivacyGuard

PrivacyGuard.redact_task runs Microsoft Presidio across PERSON, LOCATION, PHONE_NUMBER, and EMAIL_ADDRESS entities alongside a custom street-address recognizer. ExecutiveAgent.execute sanitizes the user prompt prior to LLM dispatch.

from govagent.policy import Policy
from govagent.guards.privacy import PrivacyGuard

guard = PrivacyGuard(Policy({"metadata": {"agent_name": "PrivacyDemo"}}))
print(guard.redact_task("Pay John Doe at 123 Main St for invoice #99."))
Verified Output

Use Case 6: Harbor OCI Artifact Verification HarborVerifier

HarborVerifier queries Harbor v2 APIs when configured with a live robot token (HARBOR_ROBOT_TOKEN). Tokens matching "mock-token", "mock", or starting with "mock-" operate in offline stub mode, rejecting repositories containing malicious and passing all others. registry.verify_and_resolve_tool triggers verification whenever both oci_repository and artifact_digest are declared on @tool.

from govagent.registry.harbor_verifier import HarborVerifier
from govagent import tool, registry

h = HarborVerifier(robot_token="mock-token")
print(h.verify_tool_artifact("bizzteq/finance-utils", "sha256:abc"))
print(h.verify_tool_artifact("malicious/wipe", "sha256:abc"))

@tool(name="database_wipe", risk_level="high",
      oci_repository="malicious/db", artifact_digest="sha256:dead")
def database_wipe():
    return "wiped"

registry.verify_and_resolve_tool("database_wipe")

Use Case 7: Policy-Based LLM Router PolicyBasedRouter

RoutingMode supports LOCAL_ONLY, CLOUD_ONLY, and HYBRID. Initialization raises a ValueError if default_provider is absent from the clients dictionary. Conditional RoutingRule evaluation executes only in HYBRID mode.

from govagent.llm.router import PolicyBasedRouter, RouterConfig, RoutingMode, RoutingRule
from govagent.llm.base import BaseLLMClient, LLMRequest, LLMResponse

class Dummy(BaseLLMClient):
    async def generate(self, request: LLMRequest) -> LLMResponse:
        return LLMResponse(text="ok", model_name="dummy", raw_usage={"total_tokens": 1})

clients = {"local_ollama": Dummy({}), "cloud_openai": Dummy({})}
hybrid = PolicyBasedRouter(clients, RouterConfig(
    routing_mode=RoutingMode.HYBRID,
    default_provider="local_ollama",
    rules=[
        RoutingRule(condition_key="contains_pii", expected_value=True, target_provider="local_ollama"),
        RoutingRule(condition_key="tool_complexity", expected_value="high", target_provider="cloud_openai"),
    ],
))
print(hybrid.determine_target({"contains_pii": True}))
print(hybrid.determine_target({"tool_complexity": "high"}))
print(hybrid.determine_target({}))

Use Case 8: Evidence Pack, CFO Analytics & MetaGovernor govagent.governance

govagent.governance exports MetaGovernor, CFOAnalyticsEngine, ComplianceDossier, and EvidencePackGenerator for post-execution audit, financial telemetry, and autonomous policy tuning.

EvidencePackGenerator

Ingests a JSONL audit buffer (defaulting to logs/audit_buffer.jsonl). BLOCKED or VETOED events increment EU AI Act Article 9 counters when block_reason matches PII/PRIVACY, SEMANTIC, or HARBOR/CVE. Calling seal() computes a deterministic dossier_sha256 digest.

from govagent.governance import EvidencePackGenerator

dossier = EvidencePackGenerator(buffer_path="audit.jsonl").generate(system_anchor="govagent-help-demo")
print(dossier.framework_version, dossier.dossier_sha256)

CFOAnalyticsEngine

record_execution (aliased as record_snapshot and record_transaction) aggregates recursive_tco_usd and total_tokens by cost_center (default CC-GENAI-DEFAULT, GL GL-640100-SOFTWARE). analyze() accumulates requested_exposure_usd into value-at-risk for exact BLOCKED or PENDING statuses and flags burn_rate_anomaly_detected when spend exceeds 0.50.

MetaGovernor

analyze_friction() inspects a JSONL audit trail (default logs/audit_trail.jsonl). Entries whose status contains both REJECT/BLOCKED and TCO/FISCAL increment the friction counter. Reaching friction_threshold (default 3) emits a POLICY_AMENDMENT_PROPOSAL setting proposed_limit = max(current_limit * 1.20, avg_request * 1.10):

SemanticGuard Calibration Note: Evaluated against the sample finance prohibited strategies list, an empty string returns 1.0, a standard budget query scores ~0.813, and an overtly adversarial prompt (“We should pursue aggressive tax avoidance and predatory pricing against patients.”) scores ~0.293. Because SemanticGuard triggers a breach (0.0) when cosine similarity exceeds the configured threshold, setting min_similarity_score: 0.85 is permissive for all-MiniLM-L6-v2; thresholds around 0.30–0.45 provide tighter semantic enforcement.
